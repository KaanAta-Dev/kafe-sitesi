# Limon Kafe

Akdeniz esintili kurgusal bir kafe için hazırladığım tanıtım sitesi.

🔗 **Canlı site:** https://kaanata-dev.github.io/kafe-sitesi/

## Kullanılan teknolojiler

- HTML
- CSS (Flexbox, Grid, media query, CSS değişkenleri)
- JavaScript

## Özellikler

- Telefon, tablet ve bilgisayarda uyumlu görünüm
- Kategorilere ayrılmış, sekmeli menü
- Tıklayınca büyüyen fotoğraf galerisi (lightbox)
- Doğrulamalı rezervasyon formu
- Telefonda açılır kapanır menü

## Not

Sitedeki görseller yapay zekâ ile üretilmiştir. Kafe ve bilgileri kurgusaldır.
